# BookBot

BookBot is a Python command-line tool that analyzes plain-text files and outputs a formatted statistical report of total word counts and alphabetical character frequencies.

## Key Features & Tech
* **Python:** File I/O operations, string manipulation, dictionary data structures, and custom sorting.
* **CLI & Linux:** Executed and tested in a Linux shell environment.
* **Git:** Developed using structured commits and version control workflows.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com
   cd BookBot
   ```

2. Run the script with a path to any `.txt` file:
   ```bash
   python3 main.py path/to/book.txt
   ```
